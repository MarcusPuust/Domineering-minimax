# Domineering Minimax

This project is a simple web page for a Domineering game project. The current version includes the page title, a short description, a 4 by 4 board, basic move validation for both players, win detection, and a New Game reset button. AI is not included yet.

## Files
- `AGENTS.md` — project rules and instructions.
- `index.html` — page structure.
- `style.css` — page and 4 by 4 board styling.
- `script.js` — creates the board, validates both players' moves, detects wins, and resets the game.

## Run it locally
1. Open `index.html` in a browser, or
2. Start a local web server in the project folder:

   python3 -m http.server 8000

Then visit `http://localhost:8000` in the browser.

## Notes
- No external libraries are used.
- This project is intentionally kept simple for the first step.
