# Project instructions

This is a school project called "Domineering Minimax".

## Game rules

- Use a 4 by 4 Domineering board.
- Player 0 is the human player and places vertical 1 by 2 pieces.
- Player 1 is the computer and places horizontal 1 by 2 pieces.
- A player loses when they have no legal move.

## Technical restrictions

- Use only HTML, CSS and JavaScript.
- Do not use external libraries.
- Keep the code beginner-friendly and commented.
- Keep the project runnable by opening index.html.

## Development process

- Work step by step.
- Do not add a new major feature until the current feature is tested.
- After every task, explain what files changed and how the result was tested.
- Keep a development diary in README.md.
- Add each development prompt, result, problem, and fix to the diary.

## AI and optimisation requirements

- First create a simple computer opponent that chooses a legal move.
- Later add minimax with a limited search depth.
- Then add alpha-beta pruning.
- Show the search depth, number of checked states, and time used in milliseconds.
- Allow comparing normal minimax with alpha-beta pruning.
- Explain in README.md whether alpha-beta pruning reduced the number of checked states.

## GitHub requirements

- Keep README.md updated with setup and play instructions.
- Include a section for the GitHub repository link.
